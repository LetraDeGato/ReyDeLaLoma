# [Nombre de Tu Juego] *(Inspirado en "El Viaje del Rey de la Pradera")*

![Captura de pantalla del juego](URL_IMAGEN_PROMOCIONAL.png) *<!-- Añade una imagen llamativa -->*

## 📝 Descripción  
Un juego de aventuras en 2D/3D híbrido donde controlas a un personaje en un mundo inspirado en *Stardew Valley*, con mecánicas de movimiento avanzado (escalada, natación, empuje de objetos) y combate con disparos.  

**Características principales**:  
- Movimiento en tercera persona con cámara suave.  
- Sprites 2D en un entorno 3D.  
- Sistema de economía y HUD interactivo.  
- Niveles desafiantes con obstáculos y enemigos.  

## 🎮 Controles  
| Tecla | Acción |  
|-------|--------|  
| `WASD` | Movimiento |  
| `Shift` | Correr |  
| `Espacio` | Saltar |  
| `E` | Interactuar/Empujar |  
| `Ratón` | Apuntar y disparar |  

## 🛠️ Tecnologías  
- **Motor**: Unity 2021.3+  
- **Lenguaje**: C#  
- **Assets**: Sprites 2D, modelos 3D low-poly, sonidos 8-bit.  

## ⬇️ Instalación  
1. Descarga la última versión desde [itch.io](URL_ITCH_IO) o clona este repositorio.  
2. Ejecuta `NombreDelJuego.exe` (Windows) o abre el proyecto en Unity.
